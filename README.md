# Shanghai, a little closer

A mobile-friendly Shanghai food map and a few practical travel tips. Optional inspiration for two travellers, with Chinese restaurant names and Amap links.

## Hosting

This is a plain static site. In GitHub Settings → Pages, choose **Deploy from a branch**, select **main** and **/(root)**, then save. No build step or custom domain is required. Relative asset paths work under a GitHub Pages project path.

## Content and map

Restaurant records were compiled on 27 September 2026. Check current branches, opening hours and the exact Chinese address before visiting. Some overview pins indicate a building or wider complex; the guide identifies these explicitly.

Leaflet is bundled locally. The map uses OpenStreetMap tiles and requires network access to that service. Address cards and Amap links remain usable if map tiles cannot load.
